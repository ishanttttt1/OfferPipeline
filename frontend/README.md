# OfferPipeline Frontend

React frontend for the OfferPipeline job and internship application management platform.

## Current Features

- User authentication
- User profile management
- Company CRUD interface
- Application CRUD interface
- Application status tracking
- Application date validation
- Application notes with character counter
- Form validation
- Responsive modal-based interfaces
- Django REST API integration

## Tech Stack

- React
- JavaScript
- CSS
- Vite

## Development

The frontend communicates with the OfferPipeline Django REST API for authentication, company management, and application management.
